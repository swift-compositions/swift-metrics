# swift-metrics

> **Status: Namespace-reservation**

Namespace reserved for counter, gauge, and timer instrumentation in Swift.

This repository is scaffolding. The namespace and an initial type sketch exist,
but there is no usable API yet and no released version. It becomes a documented,
installable package when the instrumentation surface is implemented.
